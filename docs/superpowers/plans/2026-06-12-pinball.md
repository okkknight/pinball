# Pinball Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a macOS desktop toy app that renders a draggable pinball launcher, launches a ball into a transparent click-through overlay, and bounces the ball off screen edges and visible window rectangles without blocking normal desktop interaction.

**Architecture:** Use a SwiftPM workspace with a library target for pure physics/window-scanning helpers, an executable target for AppKit lifecycle and SpriteKit rendering, and a small build script that stages a project-local `.app` bundle for launch. Keep the overlay and launcher as separate AppKit windows, with SpriteKit handling the ball scene and a polling scanner feeding window bounds into collision logic.

**Tech Stack:** Swift 6, AppKit, SpriteKit, CoreGraphics, Swift Package Manager, XCTest.

final class CollisionManagerTests: XCTestCase {

        let bounds = CGRect(x: 0, y: 0, width: 1000, height: 800)
        let state = BallState(position: CGPoint(x: 6, y: 400), velocity: CGVector(dx: -300, dy: 0))

        let result = CollisionManager.resolve(ball: state, within: bounds, obstacleRects: [], config: config, deltaTime: 1.0 / 60.0)

        XCTAssertGreaterThan(result.velocity.dx, 0)
        XCTAssertGreaterThanOrEqual(result.position.x, config.ballRadius)
    }
}
